# Changelog

All notable changes to this project are documented here. Format based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.2.0] – 2026-10-21

### Added
- Event `totalenergies_stations_fuel_availability_changed`, fired on every available ↔ unavailable
  transition of a configured fuel (not on the first refresh, never for `unknown`).
- Option **persistent notification** (off by default): shows a Home Assistant notification when a
  fuel is available again.
- Automation blueprint `blueprints/automation/totalenergies_stations/fuel_available_notify.yaml`
  (state trigger, optional price threshold) + import badge in the README.
- Local brand assets (`custom_components/totalenergies_stations/brand/`, own neutral icon, HA ≥ 2026.3)
  generated by `scripts/make_brand.py`.
- `loggers` in `manifest.json`. (`categories` is intentionally not set yet: the hassfest action
  image still rejects the key; it will be added once hassfest supports it.)
- Unit tests for change detection (`tests/test_events.py`).
- `CHANGELOG.md`, Dependabot config, issue templates.

### Changed
- `hacs.json`: `country` (`FR`), minimum Home Assistant version `2026.3.0`, `render_readme`.
- README: icon, badges, notification section (FR/DE/EN), CI notes updated.
- `examples/automation_fuel_available.yaml`: state-trigger and event-trigger variants.

## [0.1.0] – 2026-10-21

### Added
- Initial release: config flow (radius search or manual station IDs), options flow (poll interval,
  fuels), price sensors, availability binary sensors, opening-status sensor, diagnostics,
  translations FR/DE/EN, CI workflow (hassfest, HACS action, ruff, pytest).
